In practice

Look over our shoulder.

  1. 01

    Write it in Python

    An agent is a few lines of code with real tools attached: git, Helm and kubectl.

  2. 02

    Let AI agents do the legwork

    Test, infrastructure and review agents work through the plan while an engineer watches and approves.

  3. 03

    Ship it on Kubernetes

    A rolling update into production, verified pod by pod, with rollback one command away.

agent.py
from esensible import Agent, tools

deploy = Agent(
    name="release-bot",
    tools=[tools.git, tools.helm, tools.kubectl],
)

plan = deploy.plan("ship customer-portal v2.4")
for step in plan:
    step.run(verify=True)
